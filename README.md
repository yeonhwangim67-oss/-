# 대해적시대 연대기

원피스 세계관 텍스트 인생 시뮬레이션 (정적 웹사이트). `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

## 규칙
- **시간**: 1분 = 1살, 15초 = 1계절. 계절이 바뀔 때마다 30% 확률로 이벤트 발생. 속도 x1~x16, 일시정지(스페이스).
- **스탯** (0~100, 평판만 -100~+100): 체력 70, 식량 30, 평판·인맥·선원 0으로 시작. 재산은 집안에 따라 다름.
- **10살**: 꿈 선택(해적 / 해군 / 평범) → 테크트리 개방. **18살**: 해적 출항 / 해군 입대 / 고향에 남기.
- **해적**: 해적 → 칠무해 → 사황 → 대해적(해적왕). 현상금·선원·인맥·로드 포네그리프 조건 충족 시 승급 이벤트.
- **해군**: 해적 체포 공적으로 진급 (잡병 → … → 대장 → 원수).
- **악마의 열매**: 초인계 / 동물계 / 자연계. 전투 사망 확률 감소(×0.6 / ×0.5 / ×0.35), 대신 바다에 빠지면 위험.
- **시드**: 같은 시드 + 출생지 + 선택이면 같은 인생.
- **출생지 난이도**: EZ(홀케이크 아일랜드 등) / NORMAL(후샤 마을 등) / HARD / EX(오니가시마).

## 파일
- `index.html` — 화면 구조
- `style.css` — 스타일
- `game.js` — 게임 로직 (데이터·이벤트·시드 난수·루프·렌더링)
