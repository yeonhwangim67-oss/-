# 대해적시대 연대기

원피스 세계관 텍스트 인생 시뮬레이션 (정적 웹사이트). `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

## 규칙
- **시간**: 1분 = 1살, 15초 = 1계절. 계절이 바뀔 때마다 20% 확률로 이벤트 발생. 속도 x1~x16, 일시정지(스페이스).
- **스탯** (0~100, 평판만 -100~+100): 체력 70, 식량 30, 평판·인맥·선원 0으로 시작. 재산은 집안에 따라 다름.
- **8살**: 첫 스승 선택 (검술 사범 / 무술가 / 항해사 / 의사). 검술은 스승이나 도장을 거쳐야 수련할 수 있다.
- **10살**: 꿈 선택(해적 / 해군 / 평범) → 테크트리 개방. **18살**: 해적 출항 / 해군 입대 / 고향에 남기.
- **해적**: 해적 → 칠무해 → 사황 → 대해적(해적왕). 조건(현상금·선원·인맥·로드 포네그리프)을 채우면 승급 이벤트가 반드시 찾아온다. 현상금·선원·인맥은 해마다 자란다.
- **네임드 해적단**: 흰수염·빨간 머리·빅 맘·백수·검은수염·밀짚모자·하트·키드·호킨스. 14~17세 스카우트로 입단하면 해적단별 이점을 얻고, 22세 이후 독립할 수 있다. 네임드 해적단과 싸우면 즉사 위험이 있다(열매·견문색으로 감소).
- **선원 수**: 바다에서 싸울 때 선원 수에 비례한 전투력 보정.
- **해군**: 해적 체포 공적으로 진급 (잡병 → … → 대장 → 원수).
- **악마의 열매**: 초인계 / 동물계 / 자연계. 전투 사망 확률 감소(×0.6 / ×0.5 / ×0.35), 대신 바다에 빠지면 위험.
- **시드**: 같은 시드 + 출생지 + 선택이면 같은 인생.
- **출생지 20곳 + 무작위**: EZ(홀케이크 아일랜드 등) / NORMAL(후샤 마을 등) / HARD / EX(오니가시마).
- **가문 10종 + 무작위**: D의 일족, 빈스모크, 코즈키, 샬롯, 네펠타리, 해군 영웅, 돈키호테, 엘바프 전사, 루나리아족 등. 전투·성장·전용 이벤트가 달라짐.
- **기술**: 검술, 육식(면도·철괴·지건·월보·람각·체풍 → 육왕총), 견문색·무장색·패왕색. 매 계절 고른 「수련 방향」으로 성장하고, 훈련 이벤트와 스승 이벤트로 크게 오름.
- **체력**: 자연 회복은 아이 75 / 어른 80까지만. 그 이상은 휴식·치료 이벤트로. 나이가 들어도 체력은 줄지 않고, 50세부터 해마다 노환으로 죽을 확률이 오른다(장수의 비결·거인족은 크게 감소).
- **식량**: 기본적으로 매 계절 줄어든다. 사건 선택(낚시·사냥·구입·약탈)으로 채워야 하고, 10 아래로 떨어지면 식량 위기 이벤트가 찾아온다.
- **돈키호테 가문**: 성지 마리조아에서 천룡인으로 태어나, 8살에 지상으로 추락한다.
- **세계의 큰 사건**: 정상전쟁, 임펠 다운 대탈옥, 오니가시마 결전, 세계회의. 스탯 변화 없는 세계관 이야기도 가끔 나온다.
- **희귀도**: 인생이 끝나면 각 기록이 전체 인생 중 몇 %에서 나왔는지 보여준다 (`tools/gen-rarity.js`로 무작위 인생을 시뮬레이션해서 계산).
- **화면**: 왼쪽은 인물 정보·스탯, 가운데는 사건 기록, 오른쪽은 직접 고르는 수련 방향·기술·열매.
- **이벤트 재등장 대기**: 같은 이벤트는 최소 2년 뒤에 다시 나온다.

## 파일
- `index.html` — 화면 구조
- `style.css` — 스타일
- `data.js` — 출생지·가문·집안·열매·기술 데이터
- `events.js` — 이벤트 목록
- `rarity.js` — 기록별 희귀도 표 (자동 생성)
- `tools/gen-rarity.js` — 희귀도 표 생성기 (`node tools/gen-rarity.js 8000`, playwright 필요)
- `game.js` — 엔진(시드 난수·전투·성장·루프)과 화면 렌더링
